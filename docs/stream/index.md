# The Stream

**Weekly distilled digests of what shipped in GenAI — and why it matters.**

The GenAI ecosystem moves fast enough that news from two weeks ago is already
context. The Stream cuts through: each digest is one page, readable in five minutes,
written by the Gardener agent from a structured survey of provider changelogs, major
library releases, and research that crossed a practical relevance threshold.

## What the Gardener watches

- Provider release notes (model updates, API changes, pricing changes)
- Major library releases (frameworks, tooling, evaluation libraries)
- Research papers that have moved into practice — not every preprint, only the ones
  builders are actually using
- Deprecations and breaking changes that affect production systems

## What a digest is *not*

The Stream is not a paper summary feed, a hype tracker, or a link dump. Each item
answers: **what changed, what it means for builders, and whether you need to act.**
Items that don't clear that bar are dropped.

## Reading order

Digests are published newest-first. If you are catching up, read from the oldest
digest forward — context accumulates.
